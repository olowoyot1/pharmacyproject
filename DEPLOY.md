# OAATZ Zoho Books 3-Outlet Proposal Landing Page

Static deployment package for the OAATZ Cosult Ltd proposal.

## Deploy to Vercel
1. Extract this folder.
2. Import the folder/project into Vercel, or run `vercel` from the folder.
3. No build command is required.
4. Output directory is the project root.

## Deploy to cPanel/other hosting
Upload `index.html` and the included assets to the public web root.

The landing page is self-contained and uses the OAATZ branding already embedded in the page.
